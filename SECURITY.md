# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub:
**Security → Report a vulnerability** on this repository
([private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).

Include what you found, how to reproduce it and the app version. We aim to acknowledge
reports within 5 working days and to agree a disclosure date with you.

## Supported versions

Only the latest release on Google Play receives security fixes.

## Scope

The app has no backend. All contraction data is stored on the device; optional backups go
to the user's own Google Drive app-data folder. Issues in how the app stores, exports or
backs up that data are in scope.
